# That is ChatGPT Code 🎨

Ever wondered what your photos would look like as ASCII art? Well, wonder no more! "That is ChatGPT Code" is a cheeky little browser-based tool that turns your ordinary images into retro ASCII masterpieces.

## Features ✨

- Upload any image straight from your computer.  
- Converts it into ASCII in real-time.  
- Works entirely in your browser, no installation needed.  
- Retro green-on-black monospace style by default.  
- Adjustable width for ASCII output (currently fixed at 100 characters wide).  
- Lightweight and fun for experiments, jokes, or just showing off to your mates.  

## How to Use 🚀

1. Open `index.html` in any modern browser.  
2. Click the **Choose File** button and select an image.  
3. Your image will be transformed into ASCII art instantly.  
4. Copy the ASCII text, admire it, or share it for maximum banter.  

## Files Included 📂

- `index.html` — the main HTML page to open in your browser.  
- `style.css` — contains styling for the ASCII art output.  
- `engine.js` — the engine that converts your images to ASCII magic.
